# Linear Regression Project 📊

A small hands-on project to practice **Linear Regression** and understand the basics of building and evaluating a Machine Learning model.

## Project Overview
In this project, I worked through the main steps of a Linear Regression workflow, from exploring the data to evaluating the model's predictions.

## What I Practiced
- Data Exploration
- Data Preprocessing
- Train-Test Split
- Building a Linear Regression Model
- Making Predictions
- Model Evaluation

## Evaluation Metrics
I used the following metrics to evaluate the model:

- **MAE** – Mean Absolute Error
- **MSE** – Mean Squared Error
- **RMSE** – Root Mean Squared Error

## Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## What I Learned
This project helped me better understand how Linear Regression works and how to evaluate a model's performance.
